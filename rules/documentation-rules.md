# Documentation Rules

## Mục Tiêu

- Mọi thay đổi hành vi, kiến trúc, schema, route, hoặc vận hành quan trọng phải có dấu vết tài liệu hóa.

## Quy Tắc

- Cập nhật `context/project-context.md` khi hiểu biết về dự án thay đổi đáng kể.
- Cập nhật `context/routes-map.md` khi route thay đổi đáng kể.
- Cập nhật `context/database-schema.md` khi schema thay đổi đáng kể.
- Cập nhật `memory/changelog.md` cho thay đổi hành vi hoặc kiến trúc.
- Cập nhật `memory/progress.md` sau mỗi task.
- Ghi assumptions và workaround vào `context/decisions.md`.

## Checklist

- [ ] Progress đã được cập nhật
- [ ] Changelog đã được cập nhật nếu có thay đổi hành vi
- [ ] Routes map/schema/context đã được cập nhật nếu task ảnh hưởng
- [ ] Decision log đã ghi assumption hoặc workaround cần thiết
