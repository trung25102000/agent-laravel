# SOLID Rules

## S - Single Responsibility

- Mỗi class chỉ có một trách nhiệm

## O - Open/Closed

- Có thể mở rộng
- Không sửa code cũ quá nhiều

## L - Liskov

- Child class thay thế được parent

## I - Interface Segregation

- Interface nhỏ gọn
- Không ép implement method dư thừa

## D - Dependency Inversion

- Phụ thuộc abstraction
- Không phụ thuộc implementation

## Additional

- Ưu tiên composition over inheritance
- Ưu tiên dependency injection
