# Prompt Review

Review toàn bộ project Laravel này theo góc nhìn senior reviewer.

Yêu cầu review:

- Security
- Performance
- Laravel convention
- Clean code
- Architecture consistency
- Missing tests
- Potential regressions

Cách làm:

1. Đọc toàn bộ `/rules`, `/context`, `/memory`, và codebase liên quan.
2. Review theo mức độ nghiêm trọng, ưu tiên bug, risk, security issue, performance issue, và thiếu test.
3. Chỉ ra file hoặc khu vực ảnh hưởng.
4. Nếu không thấy lỗi rõ ràng, nêu residual risks và testing gaps.

Không ưu tiên tóm tắt dài. Ưu tiên findings cụ thể, actionable, và có căn cứ kỹ thuật.
